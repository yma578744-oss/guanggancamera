# 光场相机（Android 原型）

这是一个原生 Android / Kotlin 相机原型。拍摄后在本机执行确定性的非生成式像素处理，并将成片保存到系统相册。

## 当前实现
- CameraX 后置摄像头预览与高质量 JPEG 拍摄
- 拍摄完成后自动进行本地后期
- 宽幅、连续的全局方向性亮度场
- 对比度曲线与轻度色彩密度增强
- 输出保存到 `Pictures/光场相机`
- 不上传照片、不调用生成式 AI

## 当前限制
- 这是第一版算法原型，不是已经验证过所有机型的正式发布版。
- 目前通过画面亮度质心估算整体方向，无法可靠理解三维场景、语义主体或真实反射。
- 算法不会重绘物体，但也不会真正“修补/移除”干扰物；这需要额外的非生成式修复算法。
- 当前以 JPEG 输出；专业 RAW / DNG 支持、EXIF 方向完整处理、前摄切换、原图/成片对比、参数调节和机型兼容测试尚未完成。
- 处理会改变原图的色调和亮度，原始相机文件不会被覆盖。

## 构建
1. 安装 Android Studio（建议稳定版）和 Android SDK 35。
2. 解压项目，在 Android Studio 中打开 `GuangChangCamera` 文件夹。
3. 等待 Gradle Sync 完成。
4. 连接已开启开发者选项和 USB 调试的安卓手机，点击 Run。
5. 首次运行时允许相机权限。

也可在已安装 Android SDK 和 Gradle 的环境中运行：
`gradle assembleDebug`

APK 通常会生成在 `app/build/outputs/apk/debug/app-debug.apk`。

## 影像处理说明
本项目使用纯 Kotlin/Android Bitmap 运算，不生成新物体、不分割或替换主体、不调用网络服务。亮度质心只是启发式估算；在夜景、逆光、均匀照明或多光源场景中可能选错方向。请把它视作可运行的技术原型，先用自己的样片验证，再调整算法强度。
